1. Présentation générale

ScolaLoop est un système intelligent de transport scolaire qui optimise les trajets de bus en temps réel. Il combine :

  • Optimisation des tournées — Problème VRP (Vehicle Routing Problem) résolu par Google OR-Tools
  • Itinéraires routiers réels — Calcul via OSRM (boucle École → élèves → École)
  • Suivi GPS en temps réel — Position des bus, alertes, replay
  • Communication parents-école — Absences, SMS d'urgence
  • Gestion des élèves — Inscription, affectation automatique, import Excel

Le système s'adresse à trois types d'utilisateurs : l'administration de l'école, les chauffeurs et les parents / élèves.

L'affectation des élèves aux bus est entièrement automatique : dès qu'un élève est ajouté ou que sa position GPS est définie, le moteur VRP détermine le bus optimal et l'ordre des arrêts.

2. Connexion et sécurité

Chaque utilisateur dispose d'un compte sécurisé :

  • École (admin) : identifiant = code de l'école, mot de passe défini à l'inscription
  • Chauffeur : identifiant = code du bus, mot de passe = code du bus (à changer à la 1ère connexion)
  • Parent / Élève : identifiant = matricule, mot de passe = matricule (à changer à la 1ère connexion)

Étapes de connexion :

  1. Aller sur la page d'accueil et cliquer sur Se connecter
  2. Entrer votre identifiant (code école, code bus ou matricule)
  3. Entrer votre mot de passe
  4. Cliquer sur Se connecter

À la première connexion, un changement de mot de passe est obligatoire. Vous devez entrer un nouveau mot de passe (minimum 4 caractères) et valider.

Les mots de passe par défaut (matricule ou code bus) doivent être remplacés dès la première connexion pour garantir la sécurité.

3. Interface Administration (Tableau de bord)

Le tableau de bord est l'écran principal de l'administration. Il affiche une carte interactive avec les positions des bus, élèves et arrêts, ainsi que des panneaux latéraux pour gérer les élèves, bus et fonctionnalités.

3.1 Ajouter un élève

Étapes :

  1. Dans le panneau latéral, cliquer sur Élèves puis Ajouter un élève
  2. Remplir le formulaire : matricule, nom, postnom, prénom
  3. Saisir l'adresse du domicile de l'élève
  4. Saisir le téléphone du parent (pour les SMS)
  5. Cliquer sur Enregistrer

L'affectation au bus est automatique : le système détermine le bus le plus proche en fonction de la capacité disponible et de la position GPS de l'élève.

Un compte de connexion est créé automatiquement : identifiant = matricule, mot de passe = matricule. L'élève/parent devra changer son mot de passe à la première connexion.

3.2 Ajouter un bus

Étapes :

  1. Dans le panneau latéral, cliquer sur Bus puis Ajouter un bus
  2. Saisir le code du bus (identifiant unique)
  3. Saisir le nom du chauffeur
  4. Saisir la capacité maximale (nombre de places)
  5. Cliquer sur Enregistrer

Un compte chauffeur est créé automatiquement : identifiant = code du bus, mot de passe = code du bus. Le chauffeur devra changer son mot de passe à sa première connexion.

3.3 Importer des élèves ou bus via Excel

ScolaLoop supporte l'import en masse via des fichiers Excel (.xlsx) :

Pour les élèves :

  1. Préparer un fichier Excel avec les colonnes : matricule, nom, postnom, prénom, adresse, téléphone
  2. Dans le panneau latéral, cliquer sur Import élèves
  3. Sélectionner le fichier Excel
  4. Cliquer sur Importer
  5. Vérifier le récapitulatif : élèves importés, doublons évités

Pour les bus :

  1. Préparer un fichier Excel avec les colonnes : code_bus, nom_chauffeur, capacite
  2. Dans le panneau latéral, cliquer sur Import bus
  3. Sélectionner le fichier et cliquer sur Importer

L'import vérifie automatiquement les doublons et valide les données avant insertion.

3.4 Consulter la carte et les routes

Étapes :

  1. Depuis le tableau de bord, la carte s'affiche automatiquement
  2. Les bus sont affichés en jaune avec leur code
  3. Les élèves sont affichés avec leur domicile
  4. Les arrêts et le tracé des routes sont visibles
  5. Cliquer sur un marqueur pour voir les détails (chauffeur, capacité, etc.)

Les statistiques en haut de page indiquent en temps réel : nombre d'élèves pris, restants, taux de ramassage, alertes de retard et d'excès de vitesse.

3.5 Gérer les absences et le gel

Geler un élève :

  1. Dans la liste des élèves, cliquer sur l'icône geler (flocon) à côté de l'élève
  2. L'élève est automatiquement exclu des prochaines tournées
  3. Pour dégeler, cliquer à nouveau sur l'icône

Réinitialiser le mot de passe d'un élève :

  1. Cliquer sur l'icône réinitialiser le mot de passe dans la liste
  2. Entrer le nouveau mot de passe (2 fois pour confirmation)
  3. L'élève devra personnaliser ce mot de passe à sa prochaine connexion

3.6 Envoyer un SMS d'urgence

Permet d'envoyer un message à tous les parents des élèves d'un bus donné :

  1. Dans le panneau latéral, cliquer sur SMS d'urgence
  2. Sélectionner le bus concerné
  3. Saisir le message d'urgence
  4. Cliquer sur Envoyer
  5. Les SMS sont envoyés à tous les parents des élèves de ce bus

3.7 Enregistrer une maintenance

Étapes :

  1. Dans le panneau latéral, cliquer sur Maintenance
  2. Sélectionner le bus concerné
  3. Choisir le type d'intervention (révision, vidange, pneus, etc.)
  4. Saisir le coût et la date de l'intervention
  5. Saisir la prochaine échéance (kilométrage ou date)
  6. Cliquer sur Enregistrer

L'historique complet des maintenances par bus est visible dans le panneau de maintenance du tableau de bord.

4. Interface Chauffeur

L'interface chauffeur est optimisée pour un usage sur mobile pendant la conduite. Elle affiche une carte avec le trajet à suivre, les arrêts, et les élèves à prendre.

4.1 Démarrer la journée

Étapes :

  1. Se connecter avec le code du bus et le mot de passe
  2. Autoriser la géolocalisation quand le navigateur le demande
  3. L'indicateur GPS passe à vert : le suivi est actif
  4. Le trajet du jour s'affiche sur la carte avec les arrêts
L'écran reste actif même en mode veille (anti-verrouillage) pour ne pas interrompre le suivi GPS.

4.2 Suivre le trajet sur la carte

Éléments de l'interface :

  • Carte — Le tracé du trajet avec les arrêts et élèves
  • Statistiques — Nombre d'élèves pris, restants, total
  • Indicateur GPS — État du signal GPS en temps réel
  • Indicateur de vitesse — Vitesse actuelle en km/h
  • Guidage vocal — Activez pour des instructions audio
  • Suivi GPS — Activez/désactivez le partage de position

Activer le guidage vocal :

  1. Cliquer sur le bouton Activer le guidage vocal
  2. Des instructions audio indiquent le prochain arrêt
  3. Pour désactiver, cliquer à nouveau sur le bouton

4.3 Prendre un élève (embarquement)

Quand le bus arrive à l'arrêt d'un élève, une modale s'affiche automatiquement :

Étapes :

  1. La modale affiche le nom et matricule de l'élève
  2. Vérifier visuellement que c'est le bon élève
  3. Cliquer sur PRENDRE L'ÉLÈVE pour confirmer l'embarquement
  4. Le compteur « Pris » s'incrémente, le compteur « Restants » décrémente
  5. Si l'élève n'est pas présent, cliquer sur Annuler
Le nombre d'élèves pris/restants est mis à jour en temps réel et visible par l'administration et les parents.

4.4 Signaler un incident

En cas de problème pendant le trajet, le chauffeur peut signaler un incident :

Étapes :

  1. Dans le panneau Signaler un incident, choisir le type :
    • Embouteillage (bouton jaune)
    • Panne (bouton rouge)
    • Accident (bouton rouge)
    • Autre (bouton gris)
  2. L'incident est enregistré et visible par l'administration
  3. L'administration peut résoudre l'incident depuis le tableau de bord

4.5 Mode hors-ligne

Si le chauffeur se retrouve sans connexion internet :

  1. L'indicateur de connectivité passe à orange (hors-ligne)
  2. Le chauffeur peut continuer à marquer les élèves pris normalement
  3. Les données sont stockées localement sur l'appareil
  4. Dès que la connexion revient, les données sont synchronisées automatiquement
  5. L'indicateur repasse à vert (en ligne)
Le mode hors-ligne assure la continuité du service même dans les zones sans réseau.

5. Interface Parent / Élève

L'interface parent permet de suivre le bus en temps réel, de connaître le statut du ramassage, et de signaler les absences.

5.1 Première connexion et configuration

Étapes :

  1. Se connecter avec le matricule de l'élève et le mot de passe
  2. Changer le mot de passe (obligatoire à la 1ère connexion)
  3. La page de configuration du domicile s'affiche
  4. Sur la carte, cliquer sur votre domicile pour placer le marqueur
    OU cliquer sur Utiliser ma position GPS pour auto-détecter
  5. Cliquer sur Enregistrer pour valider la position

Dès que la position est enregistrée, le système détermine automatiquement le bus le plus proche et l'affecte à l'élève.

L'accès à l'interface parent est bloqué tant que le domicile n'est pas positionné sur la carte.

5.2 Suivre le bus en temps réel

Une fois connecté, l'interface parent affiche :

  • Carte avec le bus en jaune, votre domicile en bleu, et le tracé
  • Statut du trajet : en route, à l'arrêt, ou en attente
  • Distance restante entre le bus et votre domicile
  • Nom du chauffeur et code du bus

Fonctionnalités :

  • Le bus est localisé en temps réel sur la carte
  • Une notification sonore se déclenche quand le bus est à 100 m de chez vous
  • Le statut du ramassage indique si votre enfant est déjà pris
  • Le temps d'arrivée estimé est calculé en fonction de la position actuelle

5.3 Signaler une absence

Étapes :

  1. Sur l'interface parent, cliquer sur Signaler une absence
  2. Le bus ne s'arrêtera pas chez vous aujourd'hui
  3. Pour annuler l'absence, cliquer sur Annuler l'absence

Un élève absent est automatiquement exclu des arrêts du jour : le bus ne s'arrêtera pas à son domicile.

6. Administration générale (superutilisateur)

L'administration générale gère l'ensemble des écoles inscrites sur la plateforme.

Fonctionnalités :

  • Liste des écoles — Voir toutes les écoles avec leurs statistiques
  • Activer / Désactiver une école : désactive l'accès pour cette école
  • Statistiques globales — Nombre total d'élèves, bus, routes, taux de ramassage
  • Création d'écoles — Inscrire une nouvelle école directement
  • Suppression — Supprimer une école et toutes ses données
  • Réinitialisation des mots de passe des comptes école

Étapes pour activer/désactiver une école :

  1. Aller dans Administration générale
  2. Trouver l'école dans la liste
  3. Cliquer sur le bouton Activer ou Désactiver

Une école désactivée ne peut plus se connecter : les utilisateurs sont déconnectés et redirigés vers la page de connexion.

7. FAQ et dépannage

Q : Je ne vois pas de bus sur la carte ?

R : Vérifiez que des bus sont ajoutés et qu'au moins un chauffeur est connecté. Les bus n'apparaissent sur la carte que lorsqu'ils sont en service.

Q : Un élève n'est pas affecté à un bus ?

R : L'élève doit avoir une position GPS valide (adresse ou position sur la carte). L'affectation est automatique mais nécessite une position.

Q : Le chauffeur n'arrive pas à se connecter ?

R : L'identifiant est le code du bus, le mot de passe par défaut est aussi le code du bus. L'école peut réinitialiser le mot de passe depuis le tableau de bord.

Q : Le GPS ne fonctionne pas chez le chauffeur ?

R : Vérifiez que la géolocalisation est autorisée dans le navigateur. Si le problème persiste, essayez de recharger la page.

Q : Comment modifier la position du domicile d'un élève ?

R : L'élève/parent doit se connecter et passer par l'interface parent. L'administration ne peut pas modifier la position du domicile directement.

Q : Le mode hors-ligne fonctionne-t-il ?

R : Oui. Le chauffeur peut continuer à marquer les élèves pris sans connexion. Les données sont synchronisées automatiquement quand le réseau revient.

Q : Comment exporter les données ?

R : Depuis le tableau de bord, les boutons d'export Excel permettent de télécharger la liste des élèves par bus, les feuilles de route, etc.

Q : Comment contacter le support ?

R : En cas de problème, contactez l'administration de votre école ou ESTECH directement via le formulaire de contact sur le site.
